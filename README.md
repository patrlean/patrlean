## Selected projects / 项目选集

| Project | What it does / 做什么 |
| --- | --- |
| [Idea Flows Hook](https://github.com/patrlean/idea-flows-hook) | Track selected Codex projects with evidence-based progress updates and an optional webhook. / 用 Codex hook 跟踪指定项目的进展，支持本地记录和看板同步。 |
| [Open Math Model Agent](https://github.com/patrlean/open-math-model-agent) | A local-first workspace for mathematical modeling: from problem intake to code, paper, and verification. / 从题目、代码到论文和核验的数学建模 Agent 工作区。 |
| [MathModel Verifier](https://github.com/patrlean/mathmodel-verifier) | Evaluate modeling reports with a fixed rubric, source quotations, and programmatic score checks. / 用固定量表、原文引用和程序校验评估数学建模报告。 |
| [Verifier Benchmark](https://github.com/patrlean/math-model-verifier-benchmark) | Inject known defects into reports to test whether evaluators can detect them. / 向报告注入已知缺陷，检验评估器能否发现问题。 |
